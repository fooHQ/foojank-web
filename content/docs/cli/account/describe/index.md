# account describe

Display detailed information about a specific account, including its ID, issue/expiry dates, dependent accounts, and linked accounts.

```
$ foojank account describe [options] <name>
```

## Arguments

| Argument | Description |
|----------|-------------|
| `<name>` | Name of the account to describe |

## Options

| Option | Type | Description |
|--------|------|-------------|
| `--format` | `string` | Set output format (`table`, `json`) |
