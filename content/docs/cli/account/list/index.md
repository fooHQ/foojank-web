# account list

List all local accounts with their name, account ID, and issue date.

```
$ foojank account list [options]
$ foojank account ls [options]
```


## Options

| Option | Type | Description |
|--------|------|-------------|
| `--format` | `string` | Set output format (`table`, `json`) |
