# agent

Manage agents.

```
$ foojank agent <command>
```

## Subcommands

| Command | Description |
|---------|-------------|
| [`build`](build/) | Build an agent and create resources on the server |
| [`list`](list/) | List agents |
| [`remove`](remove/) | Remove agent resources from the server |
| [`logs`](logs/) | Display all messages in agent's stream |
