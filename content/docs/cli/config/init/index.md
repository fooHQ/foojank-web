# config init

Initialize a new configuration directory. If a configuration directory already exists at the target path, it will be reinitialized.

```
$ foojank config init [options]
```

## Options

| Option | Type | Description |
|--------|------|-------------|
| `--config-dir` | `string` | Set path to a configuration directory |
