# config list

List all configuration options with their current values and descriptions.

```
$ foojank config list [options]
$ foojank config ls [options]
```


## Options

| Option | Type | Description |
|--------|------|-------------|
| `--format` | `string` | Set output format (`table`, `json`) |
| `--config-dir` | `string` | Set path to a configuration directory |
