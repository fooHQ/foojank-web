# job

Manage jobs.

```
$ foojank job <command>
```

## Subcommands

| Command | Description |
|---------|-------------|
| [`create`](create/) | Create a job |
| [`cancel`](cancel/) | Cancel a job |
| [`list`](list/) | List jobs |
| [`logs`](logs/) | Print job's output log |
