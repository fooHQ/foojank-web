# profile

Manage profiles. Profiles are named sets of build environment variables and source directory paths that can be reused across agent builds.

```
$ foojank profile <command>
```

## Subcommands

| Command | Description |
|---------|-------------|
| [`create`](create/) | Create a new profile |
| [`edit`](edit/) | Edit a profile |
| [`list`](list/) | List profiles or their details |
| [`remove`](remove/) | Remove a profile |
| [`import`](import/) | Import profiles from a file |
